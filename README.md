# Forma — Level Up

Обновлённый дизайн приложения в premium dark green/RPG стиле.

## Что добавлено

- Первый вход: приложение спрашивает, как обращаться к пользователю.
- Главный экран в стиле Level Up: уровень, XP, миссии, быстрый расход.
- Привычки с временем выполнения.
- Напоминания по привычкам через Notification API и Service Worker.
- Удобный ввод расходов: можно писать `кофе 1200`, `такси 2000`, `обед 3500`.
- Быстрые кнопки расходов: кофе, такси, обед, магазин, аптека, связь.
- Финансовый раздел: обзор, история, бюджет, диаграммы.
- PWA: manifest, service worker, иконки.

## Важно про уведомления

Локальные уведомления работают, когда браузер/установленное PWA разрешает Notification API. Для максимально надёжных уведомлений при полностью закрытом приложении нужен серверный Web Push: backend + Push API + VAPID keys. В текущем коде подготовлена клиентская база: разрешения, service worker, обработка клика по уведомлению и локальное расписание, пока приложение активно/недавно активно.

## Запуск

```bash
npm install
npm run dev
```

## Деплой на Vercel

```bash
npm run build
```

Vercel использует `vercel.json` и папку `dist`.
